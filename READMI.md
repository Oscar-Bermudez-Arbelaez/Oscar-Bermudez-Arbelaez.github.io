# Formspree Test

Este proyecto es una prueba de integración con Formspree.

## Instalación

1. Clona el repositorio:
    ```bash
    git clone https://github.com/tu-usuario/formspree-test.git
    ```
2. Instala las dependencias:
    ```bash
    npm install
    ```

## Uso

Ejecuta la aplicación:
```bash
npm start
```

## Configuración

Asegúrate de configurar tu endpoint de Formspree en el formulario.
